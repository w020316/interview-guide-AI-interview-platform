AI 模拟面试

基于简历与岗位 JD 生成个性化面试题，再从完整性、准确性、表达能力 3 个维度评估你的回答。

RAG 知识库问答

基于 pgvector 向量检索八股文知识，支持流式回答，答案有出处可循。

求职诊断

按「证据 → 行为 → 能力 → 可投岗位信号」四层挖掘可迁移能力，给出为什么合适、差距在哪、30 天补什么 case、适合什么赛道。

投递看板

投递台账、回复监测与待跟进提醒，并针对具体岗位生成定制简历要点。

多源招聘广场

内置精选渠道，聚合 RemoteOK / Remotive / Arbeitnow 并支持自定义，统一去重入库；按关键词、行业、职位类型、地点、学历、经验、来源、招聘类型多条件筛选。

How it works

四步，把一件事做完

一条从「导入」到「跟进」的线，每一步都留下可回看的记录。

  1. 01 / 导入

    导入简历

    上传你的简历与目标岗位 JD，平台先把它读进去。

  2. 02 / 诊断

    AI 诊断

    从四个维度评分，并挖掘你的可迁移能力与适合的赛道。

  3. 03 / 练习

    模拟面试

    生成针对性问题，按完整性、准确性、表达能力逐条打磨回答。

  4. 04 / 跟进

    投递跟进

    把投递记进看板，盯回复、提醒跟进，别让机会停在已读。
