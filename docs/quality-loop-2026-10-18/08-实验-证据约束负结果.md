# AI 评测 · 实验记录：「先引原文再打分」失败（负结果）

> 时间：2026-10-18 20:44–21:10
> 基线：v1.72.0（维度加权聚合 + v3 prompt）
> 实验：07 文档建议 2 —— 要求每个维度先给出 `evidence`（原文连续片段）再打分
> **结果：未采纳，已回滚，从未部署。** 线上仍是 v1.72.0。

---

## 一、为什么做这个实验

07 文档发现：对「主导降级为参与」「技术栈模糊化」两个变体，模型给的维度分**逐项完全相同**
（85/88/80/85）。判断是它先形成"这是一份好简历"的整体印象，再往下填维度分。

假设：如果强制它先摘原文、再打分，就能被迫逐项看内容，敏感性会回来。

## 二、怎么做的

prompt 加一条硬约束：

> 每个维度都必须先给出 evidence（必须是从【简历内容】里**原样复制**的连续片段，
> 不超过 30 字，不得改写、不得概括、不得编造），再给该维度的分数。
> 找不到可引用的原文时，evidence 留空字符串，且该维度不得高于 60 分。

同时新增一个**客观代理指标**：`证据落地率` —— 把 evidence 去掉空白后，
检查它是否真的出现在简历原文里。这比分数更难作假。

## 三、结果：两个目标一个都没达成

### 3.1 敏感性没有改善，两项还退步了

以同一轮内的 A 为基准算落差（同一模型状态下比较，排除跨轮波动）：

| 变体 | v1.72.0 落差 | v1.72.1 落差（加 evidence） |
|---|---|---|
| 删光全部量化数字 | **−8** | **−1** |
| 角色降级（主导→参与） | **−5** | **−1** |
| 技术栈模糊化 | −5 | −5 |
| 结构打乱 | −5 | −6 |

绝对值：A 89 / noMetrics 88 / weakRole 88 / vagueStack 84 / messy 83。
**「删光量化」的落差从 8 分缩到 1 分**——比不加约束还钝。

### 3.2 证据本身不可靠

```
证据落地率合计：31 / 40 = 77.5%
```

四份之一的 evidence **在原文里根本找不到**——是改写、概括或编造的。
R2 最差，只有 1/4 落地。

这条独立成立：**即便将来想给用户展示"评分依据"，现在这个质量也不能用。**

### 3.3 耗时恶化

| 样本 | v1.72.0 | 加 evidence |
|---|---|---|
| A | 17.5s | **95.4s** |
| B | 8.0s | 49.6s |
| C | 5.8s | 7.3s |

> ⚠️ 诚实标注：这组耗时**不能全部归因于 evidence**。95 秒远超"输出多 20~30% token"应带来的增量，
> 更像上游 provider 当时的抖动（同轮次里 C 仍只要 7.3 秒）。但 evidence 确实增加了输出长度，
> 方向上是变慢，这一点成立。

## 四、结论

**回滚。** 理由三条，任一条都足以否决：
1. 主目标（敏感性）没达成，两项还更差；
2. 证据只有 77.5% 可信，无法作为产品能力呈现；
3. 增加 token 与延迟，换来的是更钝的分数。

代码已恢复为 v3 口径（`ANALYSIS_VERSION` 仍为 `v3`），**与线上 1.72.0 行为完全一致，因此不需要发版**。

## 五、这次学到了什么

**prompt 层的"要求引用"改变不了打分锚定。**
模型的生成顺序是「先有整体判断 → 再补证据 → 再给分」，而不是「先查证据 → 由证据推分」。
要求它写 evidence，只是让它**为已有结论补一段看起来像原文的话**——
这恰好解释了 77.5% 的落地率。

## 六、下一步（如果还要继续追这个问题）

prompt 这条路基本走到头了。剩下三条，代价依次升高：

1. **规则化子评分**：不指望模型对"含金量"给准分，而是由代码统计可核实信号
   （量化数字出现次数、是否有主导动词、技术栈关键词覆盖），与模型分**加权混合**。
   好处：确定性、可测；坏处：会被"堆数字"优化，可能催生刷分行为。
2. **换成更强的模型**：当前 `agnes-2.5-flash` 是轻量档，评分粒度可能就是它的上限。
   代价是成本上升，需要先算一笔账。
3. **接受现状，改产品叙事**：不强调"分数涨了多少"，而强调"这四个维度各自的问题清单"。
   —— 这是最省成本、也最不容易误导用户的一条。

> 我的建议是第 3 条优先：**分数本来就不该是这类产品的主指标**，
> 建议的具体内容才是用户真正能用的东西。第 1 条可以在有明确需求时再做。
