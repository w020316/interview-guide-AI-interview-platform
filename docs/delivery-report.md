## 一、功能清单（按模块分类）

### 1. 认证与账户 ✅
- 注册/登录/登出（JWT + issuer/audience，用户名/密码/邮箱实时校验）
- Token 过期自动清除并跳转登录，401/403 统一处理

### 2. 简历分析 ✅
- 简历上传解析（PDF/TXT/MD/HTML，≤10MB）+ 解析服务
- 简历内容生成简历文本、结构化分析、智能优化、改写

### 3. 岗位分析 ✅
- JD 解析、岗位能力差距诊断、求职信/内推信生成
- 常见求职岗位维度库（jobOptions）

### 4. 模拟面试 ✅
- 按岗位生成面试题（难度分布 30% 易 / 50% 中 / 20% 难）
- **跨场题目自动生成** ⭐：难度偏好（简单/中等/困难）+ 按历史成绩自适应调节难度、聚焦薄弱环节
- **语音作答（ASR）** ⭐：Web Speech API 实时转写（Chrome/Edge）+ 语速/停顿/流畅度分析 + 表达改进建议
- 流式 SSE 作答 + AI 评判（完整性/准确性/表达力三维评分）
- **复盘报告**（综合分 + 三维可视化 + 逐题回顾 + 高频改进点）
- **复盘报告导出 PDF** ⭐：一键导出本地留档 / 打印分享
- 历史记录与会话管理、收藏题目

### 5. 知识库（RAG） ✅
- 私有知识库文档管理 + pgvector 向量检索问答
- 文档按用户隔离（userId + shared）

### 6. 学习中心四大模块 ⭐ 本次新增
- **面试日历**：月视图、新增/编辑/删除、状态管理（待面试/已完成/已取消）、当日日程 → `/calendar`
- **错题本**：按阈值(50/60/70)筛选低分题，薄弱题型定位 → `/wrong-book`
- **收藏夹**：快照式收藏重点题目/高频考点，一键移除 → `/favorites`
- **成长趋势**：SVG 折线图看得分走势、按维度掌握度分析 → `/progress`
- **趋势月/周维度 + 目标达成提示** ⭐：按 次/周/月 聚合得分，智能提示距目标差距与达成路径
- **学习中心入口页**：汇总统计，快捷进入各模块 → `/learning`

### 7. 体验与平台 ✅
- 暗色模式（系统偏好 + localStorage）⭐ 本次新增
- 顶部导航优化（间距收紧、鉴权一致、移动端滚动）⭐ 本次优化
- v4 设计系统「Calm Momentum」青绿琥珀编辑风、无障碍（SVG/焦点状态）、Loading 骨架

## 四、塑造体验评估与新功能建议

### 体验评估（SUS 视角定性）
- **核心流程**：注册登录 → 上传简历/填 JD → 开始模拟面试 → 复盘 → 错题/收藏/趋势 闭环顺畅，均 3 步内可达。
- **痛点**：面试结果暂不可导出本地；趋势看板仅整体呈现，缺乏周/月及目标对账；错题/收藏量多时无分页。

### 新功能建议（按价值/难度/优先级）
| # | 建议 | 用户价值 | 实现难度 | 优先级 |
|---|------|----------|----------|--------|
| 1 | 复盘报告 & 答题结果导出 PDF（本地留存/分享） | 高（沉淀与传播） | 中 | P1 |
| 2 | 成长趋势周/月维度 + 目标达成提示 | 中高（激励） | 中 | P1 |
| 3 | 语音作答（ASR）+ 语速/卡顿分析 | 高（表达力提升） | 高 | P2 |
| 4 | 按岗位/公司自适应出题难度与题库 | 中高 | 高 | P2 |
| 5 | 错题/收藏分页与按分类检索 | 中 | 低 | P1 |
| 6 | 多语言与无障碍深度完善 | 中 | 中 | P3 |
