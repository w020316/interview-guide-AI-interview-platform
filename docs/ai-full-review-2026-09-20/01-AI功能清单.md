> 编制日期：2026-09-20
> 审查对象：`interview-guide/`（Spring Boot 3.3.13 + Spring AI 1.0.0 + Java 21 / Vue 3 + TS + Vite + Pinia）
> 梳理方法：以**控制器暴露的 HTTP 端点**为功能入口基线，向下追至 Service 实现，向上核对前端视图；每个功能点标注实现位置与关键机制。

**功能分级口径**
- **核心功能**：用户主流程中直接产出 AI 价值的闭环功能
- **辅助功能**：支撑核心功能的输入输出、持久化、检索、统计
- **边缘功能**：容错、降级、监控、运维、安全兜底

## A. 模拟面试 AI（核心）

控制器 `controller/InterviewController.java`（`/api/interview`），服务 `service/InterviewService.java`

| 编号 | 功能点 | 端点/实现 | 关键机制与参数 |
|---|---|---|---|
| A1 | **AI 生成面试题** | `POST /api/interview/questions` → `InterviewService.generateQuestions`（L67） | 入参 `resumeText`/`jobDescription`/`count`/`difficulty`/`focusCategories`；`count` 越界夹取到 1–20（L112-113）；难度白名单（L176-181）；Redis 缓存 1h，cacheKey 含 `userId+难度+聚焦`（L73-74、L157）；RAG topK=2、每篇截 100 字（L92/L104）；响应空→`BusinessException`（L149）；JSON 经 `JsonRepairUtil.repairAndLog`（L153） |
| A1.1 | 子功能：跨场自适应难度偏置 | L176-181 | `EASY/MEDIUM/HARD/空`，空时按 3:5:2 分布 |
| A1.2 | 子功能：弱项聚焦 | L188 | `focusCategories` 逗号分隔，空则返回空串不聚焦 |
| A2 | **AI 回答评分** | `POST /api/interview/evaluate` → `evaluateAnswerWithImage`（L254） | 入参 `question`/`userAnswer`/`referenceAnswer`/`imageUrl?`；经 `AiConcurrencyGuard.call`（L282） |
| A2.1 | 子功能：多模态评分（附图） | L254 + `supabaseStorageService` | 服务端换签 10 分钟短时效签名 URL（L190）；SSRF 校验 + 仅限本系统存储域（L169-178） |
| A3 | **AI 针对性追问** | `POST /api/interview/followup` → `generateFollowUp`（L318） | 入参 `question`/`userAnswer`/`resumeText`；`question` 必填 |
| A4 | **SSE 流式答疑** | `POST /api/interview/ask/stream`（L281-422） | 事件 `start/token/done/error`；心跳 15s（L351-358）；超时 120s（L297）；虚拟线程池（L65）；双层并发闸门（全局 20 / 每用户 1，L75-79） |
| A5 | **作答附图上传（多模态前置）** | `POST /api/interview/upload-image`（L203） | 5MB 上限（L209）；类型白名单（L215）；magic bytes 校验（L219-229，SVG 一律拒绝防存储型 XSS）；命名空间取 JWT（L233） |
| A6 | 辅助：AI 接口按用户限流 | `PerUserRateLimiter`（L53-54） | 30 次/分钟/用户，覆盖 A1/A2/A3 |

## B. 智能体 Career Copilot（核心）

| 编号 | 功能点 | 端点/实现 | 关键机制 |
|---|---|---|---|
| B1 | **流式对话（ReAct）** | `POST /api/agent/chat/stream`（L81） | SSE 事件 `meta/start/token/done/error`；超时 **180s**（L88）；心跳 15s（L172-179）；取消标志 `agentCancelled` 贯穿循环（L93/L131） |
| B1.1 | 子功能：会话自动创建/续接 | `AgentService.streamChat`（L112） | 不传 `conversationId` 则新建，标题取首条消息截断 |
| B1.2 | 子功能：ReAct 多轮工具循环 | `executeLoop`（L138） | **MAX_TOOL_ROUNDS = 8**（L60）；轮次耗尽强制收尾（L167-168）；文本层工具协议（网关不支持 function calling） |
| B1.3 | 子功能：多轮记忆 | `HISTORY_WINDOW = 12`（L57） | 最近 12 条消息（约 6 轮） |
| B1.4 | 子功能：模型调用重试 | `callWithRetry`（L225-242） | 仅非 `IllegalStateException` 重试 1 次，间隔 300ms |
| B2 | 会话列表 | `GET /api/agent/conversations` | `userId` 取自 JWT（防 IDOR） |
| B3 | 会话历史消息 | `GET /api/agent/conversations/{id}/messages` | 按会话归属校验 |
| B4 | 删除会话 | `DELETE /api/agent/conversations/{id}` | 同上 |
| B5 | **工具集（9 个）** | `AgentTools.registerTools`（L69-109） | `searchJobs`(L70)、`searchWebJobs`(L75)、`matchResumeJobs`(L79)、`generateInterviewQuestions`(L83)、`deepFollowUp`(L88)、`searchKnowledge`(L93)、`getMyInterviewStats`(L97)、`listWrongQuestions`(L101)、`getUpcomingInterviews`(L105)；统一结果截断 1500 字符（L31/L448） |
| B6 | 辅助：System Prompt 注入用户画像 | `buildSystemPrompt`（L436） | 预注入薄弱分类 Top3、面试次数、平均分，减少工具轮次 |
| B7 | 边缘：SSE 并发保护 | `SseConcurrencyGuard(20,1)`（L81） | 全局 20 / 每用户 1 |
