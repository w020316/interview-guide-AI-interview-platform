# AI 智能面试辅助平台 — AI 功能测试用例设计

> 编制日期：2026-09-20
> 用例编号规则：`模块前缀-序号`。模块前缀见下表。
> 设计覆盖维度：**正常业务场景（N）/ 边界条件（B）/ 异常输入（E）/ 错误处理（H）/ 安全性（S）/ 并发性能（P）**
> 判定标准统一约定：
> - 业务成功 = HTTP 200 且响应体 `code == 200`
> - 业务失败 = 响应体 `code` 为 4xx 语义码（本项目多数场景以 HTTP 200 承载业务码，须以 `code` 为准）
> - 「已执行」标记 ✅ 表示本轮真机实测；⬜ 表示基于源码设计、本轮未执行（含原因）
