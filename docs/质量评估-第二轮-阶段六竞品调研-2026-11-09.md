## 4. SWOT（本项目）
- **S**：面试 + 简历 + 岗位 + 投递 + 知识库 RAG 全链路；后端测试 1736 例、前端 1064 例；中文场景（微信 PDF、截图识别）做得比竞品细。
- **W**：缺少删除后可恢复、错题复习调度、语音面试官；JWT 在 localStorage；Spring Boot 3.3 已停维。
- **O**：竞品验证过的“回收站/版本恢复”“分享密码”“间隔复习”都能在现有栈零依赖落地。
- **T**：reactive-resume 在简历编辑上远超本项目，不宜在编辑器上正面竞争；Render 免费层冷启动影响体验。

## 7. 风险与应对
- 关键字检索可能漏判已有功能 → 实现前逐项读代码确认，已有则撤项。
- F2 若需服务端存复习状态会触及表结构 → 先用本地存储，按规则 6 涉及 DDL 时单独评审。
- `speechSynthesis` 中文语音在各浏览器差异大 → 功能检测 + 默认关闭。
