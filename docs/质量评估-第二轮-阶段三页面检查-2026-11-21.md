### 1.1 环境事实（非产品缺陷）

- **端口与 CORS**：后端 `app.cors.allowed-origins` 只放行 `localhost:5173 / 127.0.0.1:5173`。在 5174 起 dev server 时登录被 403（前端提示「请求被安全策略拦截」）；改用 5173 后正常。属既定白名单行为。
- **种子管理员不等于管理员**：`AdminSeedInitializer` 只创建账号；`ROLE_ADMIN` 由 `APP_ADMIN_USERNAMES` 名单在签发 JWT 时决定。默认名单为「小吴同学」，因此首次以 `qa_admin` 登录拿到的是 `ROLE_USER`，访问 `/admin` 会被弹回首页。把 `qa_admin` 写入名单后恢复正常。
- **频率限制**：自动化连续访问触发 `/api/admin/**` 的 429（「请求过于频繁」），约 1 分钟后恢复。该现象由本轮高频采集引起，不计为产品缺陷；但暴露出失败态提示重复堆叠的问题（见 §4 观察 O3）。

### 3.2 导航、路由与鉴权 —— 通过

- 匿名访问 18 个 `requiresAuth` 路由，全部跳转 `/login?redirect=<原路径>`，未泄漏页面内容；

- 全部批次最终路径与目标一致，**0 意外重定向**。

### 3.3 明暗模式一致性 —— 通过

## 4. 本轮新发现问题

### S3R2-01（P2）1024×768 平板档触控目标低于 48px

| 位置 | 实测尺寸 |
|---|---|
| `views/ApplicationView.vue:1321` `.mini-btn`（前往投递/确认已投递/定制简历/一键投递/移除） | 高 31–35px；`.mini-select` 31px |

| `views/CalendarView.vue:430` `.cal-today` | 高 30px |
| `components/TodoPanel.vue:181` `.todo-refresh` | 高 29px |
| `App.vue:1264` `.version-link` | 55×24px（v1.48 曾由 18px 提到 24px，仍未达触控口径） |
| `App.vue` `.tool-chip` | 高 44px |

- **复现**：1024×768 视口，登录后打开 `/applications`、`/calendar`、`/`、`/progress`；同一元素在 768/414/375 下均为 48px。
- **判定依据**：执行计划阶段三口径「移动端触控目标 ≥48px（模板口径；严于 DESIGN.md 的 44px，按更严执行）」；上一轮 S3-05 已将 1024 导航 44px 定为 P3，本轮扩大为页面内操作控件。
- **建议**：把全局 48px 补偿断点从 `max-width: 768px` 扩到 `max-width: 1180px`，或按招聘页模式在 960–1180 区间单独补偿 `.mini-btn`、`.cal-nav`、`.cal-today`、`.todo-refresh`、`.version-link`、`.tool-chip`。
- **证据**：[`1024-applications.png`](./质量评估-第二轮-阶段三-证据-2026-11-21/1024-applications.png)、[`1024-calendar.png`](./质量评估-第二轮-阶段三-证据-2026-11-21/1024-calendar.png)、`matrix-data-recheck.json` 中 `viewport=1024x768` 记录。

## 6. 边界（必须如实标注）

- **仅 Chromium**：Firefox 未安装、WebKit 未尝试，不能据此给出跨浏览器兼容结论。
- **dev server 而非生产构建**：样式顺序与压缩差异未复验；生产构建的页面矩阵仍未覆盖。
- **AI Key 不可用**：后端启动日志显示 embedding/chat 调用 401（`Invalid token`）。因此简历分析、模拟面试、Agent、知识库 RAG、上传解析、任务中心等**生成类链路未实测**，相关页面只验证了初始态/空态/结构。
- **加载态（loading）未采样**：本地后端响应过快，未做网络限速。
- **未做生产只读冒烟**：按成本纪律不主动唤醒 Render；线上验证留到发布批次。
- **管理员数据**：`/admin` 的岗位总量/数据源来自真实渠道刷新（738 条），但高频访问会触发 429，截图中的部分面板可能显示失败态。
